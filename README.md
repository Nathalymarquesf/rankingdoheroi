# 🏆 Vítorias e Derrotas do Jogador

Este é um simples programa em **JavaScript** que calcula o **ranking** de um jogador com base no número de vitórias obtidas.  

## 🚀 Como funciona?

O programa define o nome do jogador e a quantidade de vitórias. Em seguida, usa uma **estrutura de decisão (if-else)** para determinar em qual ranking o jogador se encaixa.

### 📌 Classificação:

- **Menos de 10 vitórias** → 🏅 **Ferro**  
- **Entre 11 e 20 vitórias** → 🏅 **Bronze**  
- **Entre 21 e 50 vitórias** → 🏅 **Prata**  
- **Entre 51 e 80 vitórias** → 🏅 **Ouro**  
- **Entre 81 e 90 vitórias** → 🏅 **Diamante**  
- **Entre 91 e 100 vitórias** → 🏅 **Lendário**  
- **Mais de 101 vitórias** → 🏅 **Imortal**  

#### 🛠 Como executar?
Certifique-se de ter o Node.js instalado em sua máquina.
Copie e cole o código em um arquivo index.js.
No terminal, execute o comando:
nginx

Editar
node index.js
O resultado será exibido no console.

##### 📌 Observações
O valor da variável vitoria pode ser alterado para testar diferentes rankings.
O código pode ser adaptado para receber os valores do usuário através do prompt().
